# Validate review items with versioned evidence packs

Review generation uses a separately downloadable, language-specific Evidence Pack so validation is reproducible and independent of the generating model without bloating the extension package. Missing evidence causes a safe fallback or rejection rather than an assertion that the language is invalid, and pack upgrades revalidate affected Review Items.

The first English pack contains exactly three separately licensed inputs: Open English WordNet core asset `english-wordnet-2025-json.zip` from `2025-edition` with publisher SHA-256 `7d749f6e2c39e6970e4997839dcf6e42fd281f3c2fae0171d2192bae8cfa4b51`; the English subset derived from `wordfreq-3.1.1-py3-none-any.whl` with PyPI SHA-256 `4b1c6ecffc6198be3396d5cf871c4423ca71c907c231348d352dd54d62b97473`; and Leipzig corpus `eng_news_2023_100K.tar.gz`, whose acquisition-time SHA-256 is recorded as locally computed because the publisher supplies none. Each component retains its own source, changes, complete license, notices, and attribution. Wiktionary-derived data and hosted Wiktionary fallback are outside the first release until the extraction dependency graph and contributor-attribution mechanism are reproducible.
