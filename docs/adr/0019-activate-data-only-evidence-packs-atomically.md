# Activate data-only Evidence Packs atomically

Evidence Packs are data only and fetched from one packaged, fixed HTTPS origin with a narrowly scoped host permission: all prompts, validation rules, parsers, migrations, and executable logic ship inside the extension so remote packs satisfy Manifest V3's remote-code restriction. Each pack manifest declares language, schema and semantic versions, minimum extension version, source and license inventory, compressed and installed sizes, and content hashes; download, schema validation, size checks, and hash verification complete in staging before one atomic active-version switch, while the prior known-good pack remains available for rollback. A minimal known-good English pack ships inside the extension so first use and offline use do not depend on the host. Installation and updates disclose size and attribution and require confirmation; the first English pack is capped at 100 MiB compressed and 300 MiB installed, with larger material split or reduced rather than silently exceeding the cap. Existing review items retain pinned evidence provenance and are revalidated within the background budget instead of being silently rewritten; internal refresh does not request Chrome's user-visible downloads permission.

The unpacked release's packaged origin is `https://tzurae.github.io/lingo-palette-evidence/`. Trusted extension code constructs paths only from supported language and version identifiers; page and content-script input can never supply a URL. CI may build and verify a candidate, but publication requires manual approval by the Product Owner or repository maintainer through the protected `evidence-pack-production` environment.

Each release publishes `manifest.json` and a detached Ed25519 signature over its exact UTF-8 bytes. The verification public key ships in the extension; the Product Owner holds the private key offline and signs only after manual approval. Trusted extension code verifies the signature before parsing the manifest, then verifies schemas, sizes, and content hashes. Signature-key rotation requires an extension update and can never be directed by downloaded data.
