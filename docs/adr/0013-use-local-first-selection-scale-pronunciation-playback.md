# Use local-first selection-scale pronunciation playback

Pronunciation Playback reads the learner's entire selection—word, phrase, sentence, or longer passage—in US or UK English, prioritizing an installed matching SpeechSynthesis voice and falling back to disclosed OpenAI-generated speech when needed. Long selections are segmented at sentence boundaries and presented as one controllable queue; OpenAI chunks respect its request limit, reserve foreground budget before playback, and are cached by text, variety, voice, and model. The first release requests no microphone access and performs no pronunciation assessment.

A matching local voice has `localService === true` and an exact normalized BCP 47 language tag of `en-US` for US playback or `en-GB` for UK playback. Voice names, the browser default flag, and generic `en` tags never establish variety. If no exact local voice exists after the browser voice list is available, the disclosed fallback uses `gpt-4o-mini-tts-2025-12-15` with voice `cedar` and explicit US- or UK-English instructions. Each remote chunk satisfies both the provider's 4,096-character and 2,000-token ceilings, and playback identifies the result as AI-generated.
