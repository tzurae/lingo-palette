# Store API keys locally without syncing

Persist the Learner's OpenAI API key only in extension-local storage and read it solely for direct requests to OpenAI's official API. The key is never synchronized through Chrome or sent through a Lingo Palette backend; Settings masks it by default and documents that this boundary does not protect against extraction by an attacker who controls the browser, device, profile, or extension package. The unpacked self-use release deliberately accepts this divergence from OpenAI's guidance not to deploy API keys in client-side applications. Chrome Web Store publication is blocked until browser-held BYOK is replaced by a Lingo Palette backend proxy; backend identity, abuse prevention, billing, and operations require a separate public-release contract.

OpenAI assistance requests contain only the Selection, bounded Reading Context, Learning and Explanation Language, Action contract, and Personal Instructions where applicable. They exclude page URL, page title, DOM, Enabled Site, and Lookup history. A Lookup Record may locally retain a sanitized source URL with credentials and fragment removed and query removed by default; none of that source metadata is forwarded to OpenAI.
