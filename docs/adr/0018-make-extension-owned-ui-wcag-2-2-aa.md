# Make extension-owned UI conform to WCAG 2.2 AA

All extension-owned surfaces target WCAG 2.2 AA and remain fully operable without a pointer: selecting page text never steals focus, a discoverable configurable keyboard command enters the anchored controls, Escape closes and restores prior focus, native controls and established toolbar/tab patterns preserve reading order, and Quick Hint, playback, budget, and error status changes are announced without interruptive focus moves. The UI supports visible focus, non-color cues, reduced motion, high contrast, and 200% zoom without clipping; the first-release gate includes keyboard-only checks plus NVDA on Windows and VoiceOver on macOS rather than treating automated accessibility scans as sufficient.

The suggested entry command is `Ctrl+Shift+L` on Windows and Linux and `Command+Shift+L` on macOS. It is browser-scoped, not global. Settings reads and displays the actual Chrome command binding and directs an unbound or conflicting command to `chrome://extensions/shortcuts`; it never assumes the suggestion was accepted. Escape, Tab, Enter, Space, and arrow keys remain interaction keys and cannot be configured as the global entry command.
