# Target Chrome Desktop with Manifest V3

The first release officially supports Google Chrome on desktop through Manifest V3, including Windows and macOS, while Chrome Mobile, Firefox, Safari, and other Chromium browsers remain unverified. Its first usable build is installed unpacked for the initial learner; Chrome Web Store publication follows validation of the core reading flow, though permissions and implementation remain store-compatible from the start. Chrome-specific selection, Side Panel, permission, and lifecycle integrations stay at the extension boundary so the reading and learning model does not inherit browser-specific concepts; this favors a focused, testable first platform over premature distribution and cross-browser compatibility.

Ordinary website access uses optional host permissions, not an install-time all-sites grant. The Learner explicitly enables the current origin; Lingo Palette then persists permission and registers content scripts for its top-level documents and same-origin frames. Settings lists Enabled Sites and allows revocation. `activeTab` is insufficient for the ongoing Reading Flow, and page content can never request or choose another origin.
